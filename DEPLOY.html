♟️ 棋类游戏 · 免费跨地区联机部署指南

和异地朋友联机有两种方式：① 经公共 MQTT 中继（推荐，完全不用部署）；② 自建中继服务器（更稳，适合长期开房）。

✅ 默认就是方式 ①：双方都打开 games.html（双击即可，不用服务器、不用银行卡、不用装任何工具），一方「创建房间」拿到房间码，另一方输码「加入房间」即可。房间码经 EMQX 公共 MQTT 中继转发，纯 WebSocket，无需 WebRTC/STUN。

方式 ①：经公共 MQTT 中继（最省事，免部署）

1
你和朋友各自用浏览器打开 games.html（直接双击文件即可；需能联网，用以连接信令服务器）。
2
选同一种棋（如「中国象棋」），点左侧「联机」。
3
一方点「创建房间」，屏幕上出现 5 位房间码；把它发给朋友（可点「复制」）。
4
朋友在「房间码」框输入该码，点「加入房间」。连接成功即可对弈。
⚠️ 偶尔公共 MQTT 中继会慢或连不上：刷新页面重试，或换一个房间码重开即可。若想要 7×24 稳定公网房间，见下方方式 ②。
💡 想长期挂着、或两端网络都连不上公共信令时，才需要方式 ②（部署一个免费中继服务器）。下面步骤仍有效，但不是必须的。

整体流程

部署步骤（以 Render 为例）

1
准备 GitHub 仓库。打开 github.com/new（网页），仓库名随便起（如 chess-online），不要勾选「Add a README」(我们已有文件)。创建后复制仓库的 https://github.com/你的用户名/仓库名.git 地址。
2
一键推送到 GitHub。在本机终端进入本文件夹，运行我们提供的脚本（把地址换成你的）： bash push-to-github.sh https://github.com/你的用户名/仓库名.git 首次会让你登录 GitHub（输入用户名 + 个人访问令牌 Token，密码不行）。推送成功后仓库里就有三个文件。
3
在 Render 部署。打开 dashboard.render.com → New → Web Service → 关联刚才的 GitHub 仓库 → 配置：
Runtime: Node Build Command: npm install Start Command: npm start Instance: Free
点 Deploy，约 1–2 分钟构建完成。
4
拿到地址，开玩。部署完成后 Render 给出 https://xxxx.onrender.com。把它发给你朋友。双方都打开这个地址 → 选棋类 → 点「联机」→ 一方「创建房间」拿到 5 位房间码，另一方输码「加入」。
⏱️ 免费层会休眠：Render Free 在空闲约 15 分钟后会休眠，第一次有人打开时需要等约 30–60 秒唤醒，之后就正常了。若介意，可改用 Railway（免费额度通常不休眠，但需绑定支付方式做身份验证）。
🔒 关于加密：平台地址是 https，前端会自动用 wss:// 连服务器，平台在边缘做加密并转发明文 ws，你无需配置任何证书。

换 Railway 也行

步骤几乎一样：railway.app/new → 关联 GitHub 仓库 → 选 Node → Deploy。Railway 会自动识别 package.json 的 npm start，无需手动填命令。

本地临时自测（可选）

部署前想先确认服务器能跑，在本文件夹执行：

node lan-server.js

然后用浏览器开 http://localhost:8787/ 即可（仅本机/同 WiFi 可用，跨地区还是要走上面的部署）。
